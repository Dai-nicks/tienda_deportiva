# Frontend demo (Vite + React)

Instrucciones rápidas para ejecutar la demo localmente:

1. Ir a la carpeta `frontend-demo`:

```powershell
cd frontend-demo
```

2. Instalar dependencias:

```powershell
npm install
```

3. Ejecutar en modo desarrollo:

```powershell
npm run dev
```

La demo consume `frontend-example/api.js`. Asegúrate de que el backend Laravel esté corriendo en `http://localhost:8000` o ajusta la variable `VITE_API_URL` en un `.env` dentro de `frontend-demo`.
